📌 **Thông tin nhanh về hình dạng cây**

* Cây thường là **bụi nhỏ cao 1–3 m**, thân mọc thẳng và hơi cong nhẹ. ([YouMed][1])
* **Lá hình mác dài, màu xanh**, sắp xếp đối xứng hai bên thân. ([Nhà thuốc An Khang][2])
* **Hoa nhỏ màu đỏ/hồng**, mọc ở ngọn; đây là điểm dễ nhận biết khi cây ra hoa. ([YouMed][1])
